## 实现行为

- 每章完成学习后首次进入答题，使用无放回随机抽取10题，并随机排列每题选项。用户已明确确认同时打乱选项。
- 随机结果先原子写入存档，再显示；退出、重启、复习与答错重试沿用当前题目和选项顺序。
- 当前10题全部掌握后解锁下一章，不要求完成候选题库；后端拒绝提交未抽中的题目。
- 首次答对、已掌握、总题数和徽章统一按本轮计算，完整流程为80题；重试或复习不会重复计数。重新出发会清空全部轮次和答题记录，再进入时重新抽取。
- 小内容包少于配置题量时使用全部题目；外部包未配置quiz_size时沿用全部题目模式。旧存档中缺少轮次字段兼容为空；题库或抽题规则更新触发原有备份重开逻辑。
