# 学习分镜内容与图片来源

本文件是学习过场（`assets/content/lessons.json`）的“章节—分镜—文案—图片—来源”总账，随内容一起维护。
程序只读取 `lessons.json`，本文件用于交付、审校和溯源，不参与运行。

## 一、约定

- 文案：以团队确认稿为准，只按幕切分，不改写、不增补事实；每幕 90–150 字，阅读速度参照第一章约 3 字/秒。
- 图片：放在 `assets/content/images/<node_id>/`，`lessons.json` 内写相对于 `assets/content/` 的路径，如 `images/zunyi/event-v1.jpg`。
- 图片规格：16:9 横图，主体在中上部，底部约 25%–30% 不放重要内容（文字框所在区域），右上角避开“退出”按钮，画面内不加字幕、按钮和文字框。
- 同一幕换图时必须换新文件名（`-v1`、`-v2`…），否则学习完成记录不会被识别为已更新。
- 标记 `美术复原` 的图片是按史料氛围绘制的再现性画面，不是现场照片或文物影像；不得当作史料原件使用。
- 状态列：`已接入` = 文案与图片都已写入并被程序读取；`待文案` = 仍是占位文案；`待图` = 图片缺失，程序使用占位画面。
