## A和C如何填充

1. 打开 `assets/content/lessons.json`，找到与nodes.json一致的node_id，例如 `zunyi`。
2. 修改每幕title和text；修改末尾summary作为学习小结。占位文字可全部替换。
3. 建议将图片放到 `assets/content/images/zunyi/`；把image填写为 `images/zunyi/background.png`。路径相对于包含lessons.json的内容目录，不是项目根目录。
4. image_alt填写图片说明。建议16:9横图；播放器按要求将图片拉伸铺满窗口，不保留留白，不裁切。不同窗口比例下可能有拉伸变形，重要图像内容尽量放在中上部，避开底部居中的文字框与右上角退出按钮。支持Qt可读取的PNG/JPG等格式，建议优先PNG/JPG。
5. duration_ms按阅读量调整，单位毫秒，允许1000—120000。transition可用fade或none；fade仅控制约600毫秒淡入，不再缩放图片或移动占位山形。
6. 执行数据校验，再运行 `main.py --preview-lesson` 查看。打包版默认内置素材，修改后需重新打包；也可通过 `--content-dir` 提供完整外部内容包来预览，不改exe。

## 配置示例

```json
{
  "schema_version": 1,
  "lessons": [
    {
      "node_id": "zunyi",
      "scenes": [
        {
          "id": "background",
          "type": "image_text",
          "title": "历史背景",
          "text": "这里填写经核验的学习内容。",
          "image": "images/zunyi/background.png",
          "image_alt": "这里填写图片说明",
          "duration_ms": 12000,
          "transition": "fade"
        }
      ],
      "summary": "这里填写学习小结。"
    }
  ]
}
```

分镜数量不限于3幕，每站至少一幕；id在同站唯一。lessons条目node_id必须存在且不能重复。没有该文件或未配置的节点，自动提供三幕占位内容。格式错误会在启动/校验时明确报错；图片为空、缺失或格式无法解码时回退到占位画面，学习文字仍可阅读。

不允许绝对路径、上级目录跳转或远程URL。所有外部图片随内容目录一起交付；写图片来源和使用权限时可在text/summary中说明，或另附来源文档。当前image_alt是辅助说明，不是完整的资料引用字段。

## 运行与保存规则

- 第一次从故事页点击“开始本段学习”；即使代码调用开始答题，也会先进入播放器。
- 进入时有约850毫秒的压暗、背景浮现、文字框淡入上移过渡；正文出现后才开始计算第一幕duration_ms。过渡期间不能跳幕，退出仍可用；切出窗口暂停，点击画面或空格恢复。
- 播放期间仅保留右上角退出按钮与底部玻璃文字框；按时长自动翻页，最后保留背景、将文字框切换为学习小结。用户必须点击文字框或按回车确认，才保存学习标记并进入题目。
- 点击文字框或右方向键下一幕，左方向键上一幕，空格暂停 / 继续，R键从头重看，Esc或退出按钮返回路线。切出窗口自动暂停，点击文字框会先恢复播放，不跳过当前幕。长文字可在框内滚动阅读。
- 不强制等待时长，也不把翻页等同于实际掌握。小结界面仍可用左方向键回到最后一幕，或R键重看整段。
- 未确认小结就退出，不标记完成，下次重看。当前不保存播放到第几秒。
- 学习标记保存成功后，可直接继续答题或重看。写入失败会保留小结，允许重试。
- 旧存档缺少学习字段时保留答题记录，已通关节点可以直接复习；未通关站点需要经过学习。
- 分镜标题、文字、图片路径、时长或小结变化会更新该站学习签名，未通关节点需要重新学习，答题成绩不清空。同路径图片文件内容变更不改变签名，请用新文件名表达正式素材更新。

## 扩展接口

`LearningScene`是纯数据对象；`JsonLessonRepository`负责读取校验；`LearningPlayer`负责播放控制；`SceneRendererRegistry`负责分镜画面工厂。新增表现类型时，注册返回SceneVisual的工厂，再把注册表传给MainWindow。未来可增加路线聚焦、关键词动画，但当前仅提供image_text模板。

动画时钟统一由播放器持有。自定义渲染器优先使用phase进行绘制，不另建脱离播放器控制的计时器，保证暂停与退出能够停止所有画面变化。

`GlassTextPanel`负责底部文字与磨砂玻璃效果。玻璃横贯窗口，两侧浅、中间深，烟绿色蒙层不透明度从边缘`EDGE_ALPHA=8/255`平滑变化至中央`CENTRE_ALPHA=116/255`；背景模糊也向左右边缘渐隐。采用居中浅色文字、细微上下边线与柔和投影。背景模糊在分镜切换、淡入完成与窗口缩放后更新缓存，不每帧模糊全窗口。文字阅读区域仍约为窗口的69%，高度与底部位置沿用此前规则：按文字量自适应，最多占窗口高度的30%，超出时可滚动。
