# 山水背景与通关路线

2026年11月3日更新源码。使用用户确认的山水底图，朱红路线、节点和地名由Qt独立绘制。未生成或替换章节封面；后续已按用户请求重新打包本地exe，见[构建记录](build-2026-11-03-journal.md)。

## 素材与配置

- `assets/images/long-march-landscape.png`：2048×1152干净底图，不烘焙文字、红线和节点。
- `assets/images/landscape-provenance.json`：模型、提示词、用户参考图与生成图的SHA256。
- `assets/styles/route-map.json`：背景路径、8个节点的归一化位置、文字偏移及7个相邻节点间的贝塞尔路径。四渡赤水后的曲线路段含两个连续贝塞尔段。
- `app/ui/route_map.py`：共享图片/路线/点击坐标变换，按弧长采样，描线及到站动画。
- `app/ui/journey_bar.py`：底部横向行程栏，纸色渐变、圆点、细连接线和动态章节名；已完成站为朱红勾选，当前站为金色外环及红色标题，后续站为浅色空心点。
- `app/ui/journal_header.py`、`app/ui/journal_page.py`：B版行军手记的环形进度、一体式工具栏与右侧纸页，见[界面说明](JOURNAL_UI.md)。
- `app/ui/window.py`：导航、行程栏与右侧半透明滚动面板的组装。详情页把学习按钮放在上方，长内容可滚动。

背景在导航与底部行程栏之间铺满窗口，路线、节点及命中区域一起缩放，避免顶部会师节点被导航遮挡。右侧面板位于留白区域，保留下方出发节点及其路段；学习播放器覆盖整窗时隐藏导航与行程栏。

行程栏替代原八个方框及独立进度条，标准高度124像素。站点区域整体可点击，并支持Tab聚焦、空格/回车激活。锁定站仍可点击查看解锁说明；回看已完成章节不会移动“当前站”标记。通关状态、计数和连线从已保存成绩推导，重启恢复、重新出发归零；全部通关后八站均显示勾选。名称及数量来自内容包，单章节包可用，较多章节可横向滚动。地图示意说明保留在“使用与来源”及辅助说明中。

该图是8个章节的学习路线示意。合并章节并非单一地理点，曲线不代表精确历史地理路径、比例尺或行军里程。题库、进度签名与章节顺序不因这次视觉调整改变。

## 动画触发

完成本轮全部题目且进度写盘成功后，窗口refresh调用sync_progress，检测连续通关数量是否增加：

1. 当前站到下一站的浅红路线在1600毫秒内按弧长均匀描成朱红色，前端带小光点。
2. 到达前，下一站保持浅色；到达后节点点亮，播放850毫秒外扩光圈。
3. 最后一章没有后续线段，完成时直接在终点播放光圈。

错误答案或写盘失败不触发动画。普通刷新、切换站点与复习不会重播。同一进程连续完成多个节点会从当前绘制进度继续到新的目标；重启直接恢复已保存路段，不追播历史动画。重新出发归零并停止旧动画，进入章节学习或关闭窗口也会停止动画，避免后台遗留回调。

内置章节ID/顺序与视觉配置匹配时使用山水曲线。外部内容包章节不匹配时，保留同一背景但使用其nodes.position及相邻直线；单节点包没有线段，仍可正常学习及完成。
