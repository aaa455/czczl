# 内容包格式

A主要维护 `assets/content/nodes.json`，UTF-8编码。数组顺序就是学习顺序，增加或减少节点不用改界面代码。运行 `scripts/validate_data.py` 检查格式。

新增可选旁文件 `lessons.json`，用于每站答题前的学习过场；它不改变原nodes.json格式。图片与文字配置详见 [学习过场配置](LESSONS.md)。

## 顶层

| 字段 | 约定 |
|---|---|
| `schema_version` | 当前为1 |
| `id` | 内容包稳定ID，影响存档名称，使用英文、数字与连字符；不要使用路径字符 |
| `version` | 内容版本，例如0.1.0 |
| `title` | 标题 |
| `scope` | 历史范围与示意限制说明 |
| `review_status` | 当前draft；正式核验后可改为reviewed |
| `nodes` | 至少一个节点 |
| `quiz_size` | 可选正整数；内置为10，每章无重复随机抽题并打乱选项。缺省或null为原来的全部题目模式；题量不足时使用全部 |

## 节点

`id` 全包唯一且保持稳定；`name` 完整名称，`short_name` 用于地图标签；`time`、`place` 为展示文本；`event`、`spirit`、`modern` 分别为史事、精神解读、现实联系；`sources` 为非空来源列表；`questions` 至少一道。

`position: [x, y]` 为0—1范围的相对绘图位置，不是经纬度。请避开边缘与其他标签。合并史事与历史延伸应在正文说明，路线不是完整或精确行军路线。

## 题目

```json
{
  "id": "unique-question-id",
  "type": "single_choice",
  "prompt": "题目内容",
  "options": [
    {"id": "a", "text": "选项一"},
    {"id": "b", "text": "选项二"}
  ],
  "answer": ["a"],
  "explanation": "为什么正确，以及常见混淆。"
}
```

题目 `id` 全包唯一；选项ID在该题中唯一。答案引用选项ID，不引用显示顺序。单选答案只有一个；多选使用 `multiple_choice`，答案数组包含所有正确选项。

`sources` 应填写实际核对过的资料，推荐书名、版次、页码或官方页面标题和完整链接。当前“待A核验”是任务占位，不是已经验证的出处。

题目和选项ID与显示位置无关，随机排列不改答案。解析应直接引用选项内容，避免依赖“A项”“上一题”等位置或顺序。当前Word导入有172道候选题，逐题来源和学习覆盖核验仍待完成，见[导入与核验记录](question-bank-import.md)。

## 抽题与存档

启用`quiz_size`时，`LearningService.start_quiz(node_id)`在学习完成后抽题并原子保存；`questions_for(node_id)`返回本轮题目及已保存的选项顺序，不会触发重抽。`Progress.quiz_sessions`记录每章的`question_ids`和`option_orders`，旧存档没有此字段时默认空。后端拒绝提交未抽中的题目。

进度、解锁和统计按抽出的题目计算，内置为每章10题、共80题。退出和重启沿用原轮次；复习不会换题或重复累计成绩。重新出发会清空抽题和答题记录，随后重新抽取。JSON存档中的轮次字段结构异常会备份原存档后重开；结构合法但引用不存在的题目/选项时给出明确错误，不静默重抽。

## 对存档的影响

修改题目ID、题目文字、类型、选项、正确答案、节点/题目顺序或quiz_size，会保留旧档并重新开始。随机产生的显示顺序保存在轮次中，不改变内容签名。修改故事、解析、来源、图上位置不影响当前进度。变更节点范围或学习规则前先与B确认。
