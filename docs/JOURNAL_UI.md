# B版行军手记界面

2026年11月3日按用户确认的B版预览实现，并按用户后续请求重新打包本地exe。见[构建记录](build-2026-11-03-journal.md)。

## 视觉与组件

- `app/ui/journal_header.py`：JournalProgress绘制已完成站数和环形轨迹，首次答对计数与环形进度均来自LearningSummary。JournalTools是一体式圆角描边工具栏，使用Qt绘制的书页、信息和重置图标，提供原来的三个功能。
- `app/ui/journal_page.py`：PaperPanel绘制纸张边缘、衬页和柔和边缘阴影，避免为纸页使用嵌套Qt图形效果，保证学习入场快照正常。ChapterPage呈现朱红章节签、章节标题、时间、地点、历史记事及精神内核。
- `assets/styles/theme.qss`：维护纸色、朱红色、字体、分隔线、按钮和聚焦反馈。
- `app/ui/window.py`：组装组件，连接学习、答题、导航、回顾及重置。原有页面注册接口保留，题目、回顾、锁定说明和使用说明共用纸页外壳。

## 阅读与动作

章节页只显示历史记事与精神内核。正文区可滚动，底部主操作固定可见；长标题自然换行，长篇正文不把主操作推到纸页外。

| 当前章节状态 | 底部主操作 | 补充操作 |
|---|---|---|
| 尚未完成学习 | 开始本段学习 | 按既有规则先观看学习并确认小结 |
| 已学过、尚未通关 | 继续答题 | 重新观看本段学习 |
| 已通关、后面还有章节 | 继续前进·下一站 | 重看学习、复习本段题目 |
| 最后一章已通关 | 献上一束花·致敬长征英烈 | 重看学习、复习本段题目 |

只有全部节点完成后，最后一站才开放献花入口。点击后路线界面淡出，独立瞻仰窗口淡入；在新窗口献花后，花束和随机一位烈士的姓名、生平及对应性别的AI纪念形象淡入显示。立绘标注为AI创作，不代表真实肖像。10位人物资料保存在`assets/content/martyrs.json`。

具体章节名称、顺序和数量由内容包决定。外部单章节包完成后直接进入最终回顾。组件通过信号交给MainWindow处理动作，不另存完成标记；原有学习门槛、随机题目与选项顺序、存档及重置规则继续使用LearningService。

顶部工具支持键盘聚焦及提示，进度计数有辅助说明。进入沉浸式学习后隐藏顶部工具、纸页及行程栏，退出后恢复；原有850毫秒入场与通关路线动画继续使用。
